# Learn (`apps/learn`): instructions for every coding agent

Read the root `AGENTS.md` first; everything there applies here. This file adds
only what is specific to Learn. The Learn spec is `docs/plan/02-learn-vision.md`,
`docs/plan/03-learn-spec.md` and `docs/plan/04-bugs.md`.

## What Learn is

- Owner: **kvn**. Developed **in Suvana** and mirrored to R26-SE-019
  `learn-ssl-module/web`, which redeploys `learn-ssl-module.vercel.app` after
  every Learn milestone (`docs/plan/07-r26-mirror.md`).
- React + Vite + TypeScript. MediaPipe Tasks Vision runs in the browser; no
  video leaves the learner's device. Takes are scored by DTW against landmark
  references in `public/references/` (built by `tools/reference-converter`).
- Suvana serves Learn at `/learn/`; R26 serves it at `/`.

## Portability: every change must run unchanged in R26

- Suvana-only wiring stays inside the declared couplings
  (`docs/plan/07-r26-mirror.md` section 3). After R-01 these are only
  `suvana.config.json`, `vercel.json` and `package-lock.json`; Suvana-only
  behaviour is gated on `VITE_SUVANA === '1'`.
- Never port Suvana's `vercel.json` to R26. Never copy a lockfile between repos.
- Runtime asset paths use `import.meta.env.BASE_URL`, never a bare `/`.
- Every Learn handoff sets `r26_port: yes | no`. The port itself happens per
  milestone, from merged `main` only.

## Content and figures (hard rules, Learn form)

- **Meanings** come only from `src/data/translations.ts`, which kvn verified.
  A missing meaning shows the gloss alone. Never add an entry yourself.
- **Glosses** are the corpus filenames. Never invent one, and never describe a
  handshape, location or movement. Never draw a body or silhouette that
  implies where a sign is made.
- **Figures.** Scores are match scores, not accuracy. 74.6% separation is
  always quoted with its 65.4% majority-class baseline. Never show a number
  that was not measured: no per-finger percentages. Per-finger Correct /
  Almost / Wrong states (DN-17) stay hidden until a method passes a same-sign
  vs different-sign check (kvn 13 Oct, L-01 handoff). Label untuned constants
  as untuned in a code comment.
- **One label scale:** `band()` in `src/scoring/band.ts` (85 / 60).
- **Licences:** `kaggle_*` references are CC0; `yohan_*` are CC BY-NC-SA 4.0
  (non-commercial). No corpus video unless DN-05 allows it.
- The Hero's decorative preview cards stay as they are (kvn, 11 Oct).
- Study freeze: if a pilot is running, interaction, scoring and feedback do not
  change (none is planned).

## Code conventions

- New components get their own CSS file; grow `src/components/views.css` only
  on a day you own it (`docs/plan/10-schedule.md`).
- Hot files here: `package.json`, `package-lock.json`, `src/App.tsx`,
  `src/index.css`, `src/components/views.css`, `src/components/PracticeView.tsx`,
  `vercel.json`. One owner per day.
- New logic gets a Vitest test next to it (`*.test.ts`).
- Global keyboard shortcuts respect `e.defaultPrevented`, leave every key to
  text fields (`input`, `textarea`, `select`, `[contenteditable]`) and leave
  Enter/Space to a focused button or link (`src/app/keyboard.ts`, L-02).
- `public/wasm` is generated by `npm install` (postinstall) and
  `public/reference-index.json` by the `pre*` scripts; never edit them by hand.

## Gates (Git Bash, from `apps/learn`)

```bash
npm ci && npm run lint && npm test && npm run build
```

- No new lint warnings; tests all pass; main JS stays at or under 160 kB gzip.
- `referenceIndex.test.ts` enforces the reference-index budget; do not raise
  it to make a test pass.
- UI changes: before/after screenshots, desktop 1280x800 and phone 390x844
  (`docs/plan/08-agent-protocol.md` section 7).
