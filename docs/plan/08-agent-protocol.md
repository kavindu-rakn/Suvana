## 4. Stacking, dependencies and merge order

- Start a task only when its dependencies are merged into `main`, **or** when the dependency is your own earlier logic-only task on the same day; then branch from that branch and say so in the handoff ("stacked on agent/...").
- **UI tasks (screenshots: yes) are leaf branches:** nothing is stacked on top of them. If two UI tasks of your lane touch the same file on one day, do the second after the first is merged, or rebase it next morning.
- kvn merges stacks bottom-up only. If he rejects a branch, every branch stacked on it is rebased by its owner onto `main` the next morning.

## 5. Claims and file ownership

- **Claims:** tasks are pre-assigned on BOARD.md (owner + day). Starting = creating the branch + the first line of `docs/plan/handoffs/<ID>.md`. To take another lane's task, kvn must say so in chat (he edits BOARD.md).
- **Owned files:** each task lists its files. Touch only those, plus new files the task obviously needs (new component CSS, tests). If you must change a file owned by another task that day, put the exact proposed diff in your handoff instead.
- **Hot files** (one owner per day; see 10-schedule.md): `apps/learn/package.json` and every lockfile; `apps/learn/src/App.tsx`, `src/index.css`, `src/components/views.css`, `src/components/PracticeView.tsx`; every `vercel.json`; `tools/sync/upstreams.json`; `README.md`, `AGENTS.md`, `CLAUDE.md`, `.gitignore`, `.gitattributes`; `.github/workflows/ci.yml`; `DEPLOYMENT.md`, `DEMO.md`. Non-owners propose diffs in their handoff.
- **Agent-only edits never touch:** `docs/plan/BOARD.md`, `tasks.json`, `DECISIONS.md` (kvn's), other tasks' handoff files, `LOG.md` except appending your entry.
- **Lockfiles:** only the task that changes a `package.json` touches its lockfile, with npm 10 and Node from `.nvmrc`. Revert stray lockfile changes (`git checkout -- <lockfile>`). On a conflict, re-run `npm install` on the new base; never hand-merge.
- **New CSS:** new components get their own CSS file; do not grow `views.css` unless you own it today.
- **Line endings:** follow `.gitattributes` (after Q-02). Never reformat whole files. If `git diff --stat` shows a whole-file change you did not intend, revert it.

## 6. Workflow per task

9. If blocked: write the blocker in the handoff and LOG.md, commit what is safe, and move to your next task in the lane. Never take another lane's files without kvn's OK.
