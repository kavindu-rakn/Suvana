## Rules fixed before the experiment

- Wrong: same-sign p98; Almost: same-sign p90, strict greater-than. Nearest-rank quantile: sorted[ceil(p*n)-1]. No tuning or second candidate after results.
- Four folds, sorted corpus filenames within each sign, index modulo four. Only signs with at least eight takes. For each fold/sign, first training take is the reference; every other training take supplies same-sign deviations. The reference and thresholds never see any held-out take. One held-out take versus that reference is one correct attempt.
- Existing scoreAttempt and fingerDeviation (worst LANDMARK_FINGER joint) unchanged. Thresholds are per sign/anatomical finger, pooling measured hands; missing hands excluded and counted, never treated as correct.
- Clearly different: training source-sign takes against the target training reference, mean deviation for that anatomical finger greater than max(source same-sign p95, target same-sign p95). Both signs exclude the current fold. No held-out measurements select this population.
- All ordered pairs of qualifying signs, every held-out source take, versus the target training reference. Micro-averaged measured hand-fingers. Also report per-sign rates; no post-hoc sign selection.
- Almost means the exclusive middle state; also report Almost-or-Wrong (above p90) to remove ambiguity.
- Pass: any-Wrong correct-attempt rate <=20% AND clearly-different-finger Wrong rate >=50%. This is separation on one signer's recordings, never learner accuracy.
- JANUARY Kaggle recording: spot check only against each fold's calibration reference, never fitted or counted in acceptance.
- Read the supplied corpus in place; no corpus/report write APIs. Console output only. Phase 2 requires a pass AND kvn's explicit go in chat.
