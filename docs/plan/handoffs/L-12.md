## Proposed numbers for kvn's chat approval

These are deliberately looser reward rules, not calibrated measures of correctness. No implementation is included. DN-11 is per-browser IndexedDB with reset and a separate demo profile; DN-05 is no corpus video (skip L-15a), per kvn's 13 Oct chat.

| Rule | Earlier draft | Proposed |
| --- | --- | --- |
| First star | Try match >= 60 | Try match >= **50** |
| Second star | Try match >= 85 | Try match >= **70** |
| Third star | Recall match >= 60, unrevealed | First earn 2 stars, then Recall match >= **50**, explicitly `revealed=false` |
| Unit pass / next unlock | Every sign >= 2 stars | Every sign >= **1 star**; U1 always open, passing N opens N+1 |
| Daily goal | 10 scored attempts | **5** scored attempts per local calendar day |
| Streak | Consecutive goal days | **1 day** per day meeting the 5-attempt goal; no grace day; today unfinished keeps yesterday's streak until local midnight |
| XP | Total stars | **1 XP per earned star**, summed from each gloss's best stars; retries and alternate references cannot farm XP |
| Mastered | EWMA >= 0.85 after >= 3 attempts | Keep **0.85 / 3** for every sign in the unit; passing is deliberately easier than mastery |

Why: 50 gives a beginner an early reward; 70 leaves a useful improvement step; unrevealed Recall still rewards retrieval. One star on every sign requires visiting all items while avoiding a high-match bottleneck. Five attempts gives a short daily session. These choices are product proposals, not research findings.

Exact edge rules for approval: thresholds inclusive; keep best stars forever within the selected profile; no stars for sentence-stage attempts; scored Try/Recall/sentence attempts count toward the daily goal, while cancelled/abandoned/unscorable attempts do not. Old attempts default to Try. An unknown `revealed` value cannot earn the third star. XP is per distinct gloss in the selected profile, including signs outside approved units; no empty unit passes or masters. Streak uses local year/month/day boundaries, not 24-hour subtraction (DST safe). No account sync. Resetting a profile clears that profile's derived stars, XP, goals and streak.

Implementation follow-through if approved: L-13's Recall-unlock rule must use the approved second-star threshold (70 here); the draft 85 unlock would conflict with it. Keep L-13's below-60 retry/step-back teaching rules and existing `band()` feedback thresholds 60/85 unless kvn explicitly changes them. A two-star reward at 70 does not say "Close match". "Learned" remains >= 2 stars; mastery remains separate. K-05 still approves curriculum contents; this proposal approves no sign order or meaning.
