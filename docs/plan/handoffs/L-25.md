## Handoff 2026-10-16 - codex

### Implementation
- Appended Sentence challenge after the last approved Path unit. It unlocks
  only when that unit and its predecessors pass under the existing Path/content
  rules. Old full-corpus stars cannot bypass missing CC0 curriculum coverage.
- SentenceView is lazy-loaded and nested inside Path. Back to path stays in
  the same screen; App.tsx routing is unnecessary and untouched.
- Uses loadSentenceReferenceIndex(), then joins SENTENCES by exact recording
  ID and file. All 19 available K-07 records are offered in the existing data
  array's file order; this is a catalogue, never an invented SSL sequence.
- Every datasetLabel is rendered verbatim with whitespace preserved, including
  trailing spaces and the parenthetical label. Optional meanings come solely
  from SENTENCES' existing translationOf() mapping in sentences.ts. No content,
  labels, translations, asset JSON, manifest or curriculum edits.
- SENTENCE_EXPERIMENTAL_LABEL appears on the Path card, lazy-loading fallback,
  and every sentence view state (list, loading/failure, Watch/Try/Recall/result).
  Its sticky notice stays above player controls in both themes.
- Watch replays the whole landmark reference at 0.5x, without automatic speed-up.
  The learner can choose a speed/framing; phones initially zoom to hands. No
  source video or authored sign descriptions were added.
- Try keeps the reference visible. After a valid scored Try, Recall is cued
  by the exact dataset label with the reference hidden. Reveal is sticky for
  that take; retry starts hidden again. No uncalibrated score threshold gates
  Recall. After scoring, the reference becomes visible again for comparison.
- Uses the shared useSignCapture/useHandTracking lifecycle. Capture limit is
  exactly 2 * reference.durationMs, including long references (no isolated-sign
  cap). Countdown, cancellation, finish-early, camera errors, page-hidden abort
  and unmount cleanup are retained. Camera stops for Watch, result and leaving.
- scoreSentenceTake() trims only outer handless frames, then calls the existing
  whole-reference scoreAttempt(). No corrective hints, finger percentages,
  accuracy claims or isolated-sign reward bands are inferred for sentences.
- Every saved take, including Recall, uses stage: sentence, the actual refId
  and existing stored gloss; revealed records Recall exposure. No sentence
  stars/session queue are invented. Unusable/handless captures remain unscored;
  failed progress writes show StorageNotice while keeping the local result.
- New view-specific CSS handles 360px stage controls, wrapping labels, camera
  placeholder/playback contrast and visible focused result headings below the
  sticky notice. Shared CSS, PracticeView and hot/config/package files untouched.
