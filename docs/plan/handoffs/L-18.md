### Contract for L-21

- `ScoreResult.alignment?: Array<[referenceFrameIndex, attemptFrameIndex]>`:
  monotonic pairs in start-to-end order, indexing each original recording's
  `frames` array. These are not timestamps or filtered feature indices.
- `ScoreResult.worstFrameIndex?: number`: original **attempt** frame index
  with the greatest weighted shape + trajectory cost along the exported path.
  Ties keep the earliest path step. Use the alignment pair(s) containing that
  attempt index to find the paired reference frame for replay pause.
- Both fields are absent when no reference hand can be compared with tracked
  attempt data. Older fixtures/results remain valid because the fields are optional.
- Mirror selection follows the existing score winner. Attempt frame indices
  still index the original recording; L-21 can use the existing `mirrored` flag.
- Two-hand recordings use one replay clock: the tracked reference hand with
  the most valid frames, ties keeping reference-hand order. The worst frame is
  on that chosen hand's path, not a combined/global two-hand worst moment.
- DTW already returns its path. This change retains and remaps the winning
  path rather than recalculating DTW or changing its algorithm/tie rules.
  Existing score anchors, scores, distances, hand results and hints are unchanged.
