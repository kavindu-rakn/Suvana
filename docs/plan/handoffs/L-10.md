### Reference Metadata Implementation
- **hands (`1 | 2`):** Derived from the ratio of frames tracking $\ge 2$ hands. Constant `TWO_HAND_FRAME_THRESHOLD = 0.2` (documented as untuned UI constant). Filters MediaPipe single-frame false positives (1–5% in one-handed signs) while capturing genuine two-handed signs.
- **motion (`'still' | 'moving'`):** Derived from normalised wrist path length across the dominant hand sequence. Displacements between consecutive frames are aspect-corrected and divided by the sequence median hand scale (wrist-to-middle-finger-MCP distance). Constant `MOTION_PATH_THRESHOLD = 5.0` (documented as untuned UI constant). Signs with normalised path length $< 5.0$ are classified as `'still'`.
- **durationMs:** Extracted from recording metadata with timestamp fallback for unannotated recordings.
- **licence:** Derived from id/file prefix (`kaggle_*` -> `'CC0-1.0'`, `yohan_*` -> `'CC-BY-NC-SA-4.0'`), hoisted into the `sources` table to maintain the index compression budget.
- **hasMeaning:** Boolean indicating whether the gloss has a verified translation in `apps/learn/src/data/translations.ts` (75 glosses match).
