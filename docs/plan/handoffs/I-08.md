## Implementation

- CPU serving requirements retain TensorFlow 2.13.0 / MediaPipe 0.10.7 and
  the current web versions. The upstream desktop/training requirements are
  untouched. New requirements-runtime.txt is necessary container configuration
  within I-08; Pydantic 1.10.13 is compatible with the existing FastAPI and
  TensorFlow typing-extensions constraint. `pip check` runs during the build.
- Explicit Docker copies include only the existing trained best_model.h5,
  existing labels.npy / sinhala_labels.json, config and serving source/static
  files. Health check requires 171 classes from /api/info. PORT defaults to 7860.
- /api/info retains sequenceLength/confidenceThreshold/numClasses and adds
  labels, backend and model filename. No label generation, reordering change,
  preprocessing rewrite, model change or WebSocket protocol change.
- The static page gets a Back to Suvana link to the shell's fixed Vercel URL
  (available before the custom domain is attached) and explicit light/dark URL
  themes; invalid/missing theme retains the old dark appearance.
- README documents build/run, image contents, network boundaries and benchmark.
- New tools/benchmark_websocket.py runs the actual JPEG decode, MediaPipe,
  sliding-window model inference and WebSocket responses over synthetic blank
  frames; 29 frames fill the buffer, five predictions warm each backend,
  then 50 full windows per backend are timed. It checks /api/info, model class
  count and matching rounded wire confidences. Temporary backend overrides and
  lifespan-off/TTS suppression exist only in the benchmark process.
